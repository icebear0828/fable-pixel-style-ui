**PixelNest UI** 把 8-bit 游戏的视觉语言带进现代 Web：缺角像素边框、PICO-8 调色板、`steps()` 阶梯动效、字符网格像素画。

## 快速开始

```bash
npm install pixelnest-ui
```

```tsx
import { Button, Card, toast } from "pixelnest-ui";
import "pixelnest-ui/style";

<Card title="INVENTORY">
  <Button type="primary" onClick={() => toast.success("SAVED!")}>
    SAVE GAME
  </Button>
</Card>
```

## 如何使用本 Storybook

- 左侧目录按 **General / Form / Data / Feedback** 四类组织，与文档站保持一致。
- 每个组件的 **Docs** 页由 `autodocs` 自动生成 Props 表（来自 TypeScript 类型与 JSDoc 注释）。
- **Playground** story 开放全部 Controls，修改后可在右下角 *Show code* 复制 JSX。
- 工具栏的 **Backgrounds** 可切换 Paper / White / Ink 背景，检查组件在深色环境下的表现。

## 设计原则

| 原则 | 说明 |
| --- | --- |
| 4px 网格 | 边框、投影、间距均为 4px 的整数倍 |
| 硬边无圆角 | 不使用 `border-radius` 与模糊阴影，圆形由 20 边形 `clip-path` 近似 |
| 深色描边 | 所有可交互元素都有 ink 色描边；亮色填充 + 内阴影形成 3D 按键感 |
| 阶梯动效 | 过渡与动画使用 `steps()`，并尊重 `prefers-reduced-motion` |
